# ✨ CodeAlpha Image Gallery

A modern, responsive and interactive image gallery developed as part of my **CodeAlpha Frontend Development Internship**.

## 🌟 Project Overview

SWETHARAMESH is a stylish travel-inspired image gallery designed with a clean and modern user interface.

The gallery provides an interactive browsing experience with category filters, image previews, lightbox navigation and mobile-friendly interactions.

## 🚀 Features

- 📸 Responsive image gallery
- 🔍 Interactive image lightbox
- ⬅️ Previous and Next image navigation
- ⌨️ Keyboard navigation support
- 📱 Mobile responsive design
- 👆 Touch swipe support on mobile
- 🎯 Category-based image filtering
- ✨ Smooth hover and transition effects
- 🌙 Modern dark-themed interface
- 📐 Optimized for desktop, tablet and mobile devices

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive Web Design
